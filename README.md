# پروژه وب‌سایت رزرو غذا (رستوران آنلاین)

این پروژه یک سیستم مدیریت رستوران آنلاین است که با استفاده از PHP خام، HTML، CSS و MySQL طراحی شده است.

## ویژگی‌ها:
- **سیستم احراز هویت:** ثبت‌نام و ورود کاربران با استفاده از Session.
- **مشاهده محصولات:** نمایش لیست غذاها به همراه قیمت، توضیحات و میانگین امتیاز کاربران.
- **جزئیات محصول:** نمایش داینامیک مشخصات هر غذا و نظرات مربوط به آن.
- **نظرات و امتیازدهی:** امکان ثبت نظر و امتیاز توسط کاربران وارد شده.
- **پنل کاربری:** ویرایش نام، شماره تلفن و آدرس.
- **سبد خرید:** افزودن محصولات به سبد و نهایی کردن سفارش.
- **پنل مدیریت:**
  - آمار کلی سایت.
  - مدیریت کامل محصولات (افزودن، ویرایش، حذف).
  - مدیریت نظرات و امکان پاسخگویی مدیر به نظرات.
  - گزارش کامل سفارشات نهایی شده.

## نحوه راه‌اندازی:
1. فایل `db.sql` را در **phpMyAdmin** ایمپورت کنید.
2. تنظیمات پایگاه داده را در فایل `config/db.php` در صورت نیاز تغییر دهید.
3. تصاویر محصولات را در پوشه `assets/images` با نام‌های `1.jpg` تا `6.jpg` قرار دهید.
4. پروژه را در یک سرور محلی (مانند XAMPP) اجرا کنید.

**اطلاعات ورود مدیر:**
- ایمیل: `admin@example.com`
- رمز عبور: `admin123`

## ساختار پوشه‌بندی:
- `/admin`: فایل‌های مربوط به پنل مدیریت.
- `/assets`: فایل‌های CSS و تصاویر.
- `/config`: تنظیمات اتصال به دیتابیس.
- `/includes`: بخش‌های مشترک سایت (هدر و فوتر).
- `/products`: صفحات مربوط به محصولات، ثبت نظر و سفارش.
- `index.php`, `login.php`, `register.php`, `cart.php`, `profile.php`: صفحات اصلی سایت.
